# Tarea React

Aplicación en React con menú lateral y las siguientes páginas:

- **Inicio:** foto 2x2, nombre, apellido y correo.
- **Sumadora:** suma dos números.
- **Números a letras:** convierte un número del 1 al 1000 a letras en español (sin APIs).
- **Tabla de multiplicar:** muestra la tabla de un número hasta el 13.
- **Experiencia personal:** video de YouTube explicando la experiencia.

## Ejecutar

```bash
npm install
npm run dev
```

## Personalizar

- Coloca tu foto en `public/foto.jpg`.
- Edita nombre, apellido, correo e ID del video en `src/datos.js`.
